# Aurum Motors — демо-макет (статическая версия)

Чистый HTML/CSS/JS, без сборки и сервера. Открывается двойным кликом по `index.html`.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите все файлы из этой папки в корень (index.html должен лежать в корне).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

В страницы добавлен `noindex`, чтобы демо не попало в поиск. Пути относительные, поэтому работает и из подпапки репозитория.
Цены, авто, отзывы и контакты — демонстрационные.
